Supported Board

  • ESP32 Dev Module
  • Chip Family: ESP32
  • USB Connection Required
  • Chrome / Edge Browser

Installation Steps

  1. Connect ESP32 using USB cable.
  2. Open this page in Google Chrome or Microsoft Edge.
  3. Click Flash Firmware.
  4. Select your serial port.
  5. Wait until flashing completes.
  6. Your ESP32 will reboot automatically.

Troubleshooting

  • Use a data USB cable (not charge-only).
  • Close Arduino IDE before flashing.
  • Install CP210x or CH340 USB drivers if the board is not detected.
  • Try another USB port.
  • If connection fails, hold the BOOT button while clicking Install.
  • Refresh the page and reconnect if the serial port disappears.
Important: Do not disconnect the ESP32 while firmware is being written.
